# Template Designer

Minimal Vite + React + TypeScript starter extracted from LMS styling, tailored for Template Designer.

## Included

- LMS-like shell layout (sidebar + top bar)
- Sidebar heading: Configuration
- Single sidebar menu item: Template Designer
- Main page welcome text: Develop me Techeiiii

## Run Locally

1. Install dependencies

   npm install

2. Start development server

   npm run dev

3. Build for production

   npm run build
